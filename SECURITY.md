# Security Policy

## Responsible Use

This repository is for authorized reconnaissance and security assessment workflows. Use it only when the target program permits the relevant data sources, tools, request rates, and techniques.

Do not use these playbooks for unauthorized scanning, credential use, persistence, social engineering, denial of service, broad data collection, or access to private data that is not needed for safe validation.

## Reporting Repository Issues

Open an issue or pull request for content problems such as:

- Unsafe wording or missing stop conditions.
- Outdated tool behavior.
- Inaccurate technical guidance.
- Broken links or unclear workflow steps.
- Missing references for a claim.

Do not include live secrets, private target data, real customer information, or evidence from unauthorized testing.
